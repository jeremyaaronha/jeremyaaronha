## Projects

Some of my projects include presentation websites, small business platforms, and web applications designed to improve visibility and client interaction.

🌸 Inefable Resina — E-commerce Catalog Website

A responsive web platform developed for a small business specializing in handmade resin jewelry and personalized creations.

Technologies: Next.js, React, TypeScript, Tailwind CSS, Supabase, Cloudflare Workers, OpenNext.

Website: https://inefable-resina.inefableresina.workers.dev/ 

🗣️ Stutterers App — iOS Speech Support Application

An iOS application designed to support people who stutter by providing audio-based tools to assist with speech practice.

The application uses Apple’s AVFoundation framework to implement real-time audio processing, including delayed auditory feedback and pitch adjustment features.

Technologies: Swift, SwiftUI, AVFoundation, AVAudioEngine, AVAudioSession, Firebase, Xcode.
